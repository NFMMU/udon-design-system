全国もちもちうどん連盟のデザインシステムです。創作カタログ.jp をはじめ、連盟のサービスで共通して使います。

## 原則

- **やわらかく** — 強い断言より、余白と丸みで受け止める
- **シンプルに** — 面は白、線は1色、差し色は1箇所
- **つなぐ** — サービスが変わっても同じ作法
- **まっすぐ** — できないことはできないと言い、次の行動を示す

## 構成

| 層 | 内容 |
| --- | --- |
| トークン | 色・余白・角丸・文字。CSS 変数と Tailwind プリセット |
| アイコン | 64個。24px グリッド・線1.75 |
| コンポーネント | 27グループ。状態は props で切り替え |

## パッケージ

```bash
npm install @nfmmu/udon-react
```
