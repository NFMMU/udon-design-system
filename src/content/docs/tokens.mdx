## Tailwind

```js
import udon from "@nfmmu/udon-react/tailwind-preset";
export default { presets: [udon], content: ["./src/**/*.{ts,tsx}"] };
```

クラス例: `bg-udon-primary`、`text-udon-text`、`border-udon-line`、`rounded-udon-md`、`font-udon-heading`。
